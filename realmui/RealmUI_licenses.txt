RealmUI.dll: third-party notices

RealmUI.dll is part of Warband by Seth Summers.

Linked into the dll are two open-source libraries: CommonLibSSE NG (MinLL/CommonLibVR) and spdlog.
Used through its interface header, with nothing of it linked in but what the header holds: Prisma UI (PrismaUI_API.h),
the plugin interface Prisma UI publishes with its plugin example at https://github.com/PrismaUI-SKSE/example-skse-plugin
("For modders: Copy this file into your own project if you wish to use this API").
